# skills

Agent skills (Claude Code, Codex and other agents that read `SKILL.md`).

```sh
npx skills add jask-aran/skills
```

| Skill | What it does |
| --- | --- |
| [nasa-handbook](skills/nasa-handbook) | Technical reports styled as Apollo-era NASA operations handbook pages, opened in the browser through Artifact Server. Forked from [R44VC0RP/skills](https://github.com/R44VC0RP/skills/tree/main/skills/nasa-handbook); see its SKILL.md for what changed. |
| [fable-prompt](skills/fable-prompt) | Starter prompts for big Claude Fable 5.2 projects. A grilling interview (rounds over a design tree, after Matt Pocock's [grilling](https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling)) settles the decisions, then the prompt is written from Anthropic's [Fable 5.2 prompting guide](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-fable-5-2). |
| [grill-me](skills/grill-me) | Grill a plan, decision or idea in rounds over a design tree until every branch is decided. Self-contained merge of Matt Pocock's [grill-me and grilling](https://github.com/mattpocock/skills/tree/main/skills/productivity) (MIT), plus a rule to challenge terms that don't match the code or docs. |
| [wait-what](skills/wait-what) | `/wait-what`: re-pitch the last message with context, in plain words and the project's real names. After Matt Pocock's [wait-what](https://github.com/mattpocock/skills/tree/main/skills/productivity/wait-what). |
| [writing-for-agents](skills/writing-for-agents) | How to write skills, CLAUDE.md, system prompts and briefs: pointers, the disclosure ladder, completion criteria, leading words, positive phrasing, pruning. Condensed from Matt Pocock's [writing-for-agents](https://github.com/mattpocock/skills/tree/main/skills/productivity/writing-for-agents) (MIT). |
