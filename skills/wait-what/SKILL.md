Wait, I don't understand where you've got to here. Re-pitch that: give me a little bit of context first, talk in
ASD-STE100 Simplified Technical English, and use the real names the code and design docs use for things (the first
time a name appears, say what it is). If you coined a term during the work, replace it with the real name, or say
plainly that the thing has no name yet.
